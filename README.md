## 项目简介

快码字（QuickWrite）是一款面向小说创作者的本地写作工具。它把**作品管理、章节编辑、大纲设定、码字统计**等创作环节整合到一个界面中，让灵感与文稿都留在原地，减少在多个工具之间来回切换的成本。

- **本地优先&&云备份可选**：所有创作数据默认保存在本机，支持自选 WebDAV、S3 协议做云端备份，不绑定账号、不采集内容。
- **跨平台**：桌面端（Windows）与移动端（Android）双端适配，同一套数据与操作习惯。
- **完全免费**：没有会员制，没有任何功能限制，无需购买、无需注册、无需支付任何费用。
- **项目开源**：基于 GPL-3.0 协议开源，代码安全透明，不收集任何用户数据，无广告、无跟踪、无隐私问题。

## 功能特性

- 支持从 **docx / txt** 等文本文件**导入**作品，快速把已有作品搬进来。
- **正文编辑器**：十万字级章节依旧流畅，滚动、输入、选中不卡顿。
- **大纲编辑器**：像 Workflowy 或 幕布 那样处理你的大纲与角色、地点、势力等设定条目，支持无限层级、折叠展开、缩进与层级提升。
- **文字格式**、**页面布局**、**自定义高亮**、**查找替换**、**全文搜索**、**段落整理**、**历史版本**、**码字统计**、**云同步**、**外观自定义**、**随机取名**等等，该有的功能全都有。

## 下载与安装

应用发布在 [GitHub Releases](https://github.com/yic77455/QuickWrite/releases)，国内用户也可访问 [Gitee Releases](https://gitee.com/yic77455/quick-write/releases) 获得更稳定的下载速度。

### Windows

1. 在 Releases 页面下载最新版 Windows 安装包，文件名通常为 `quick-write-1.x.x-x64-setup.exe` 或类似格式。
2. 运行安装程序，按照提示完成安装。
3. 首次启动后可在「主界面 → 云同步」中配置 WebDAV 或 S3 服务器地址进行数据同步。

### Android

1. 在 Releases 页面下载最新版 `.apk` 安装包，文件名通常为 `quick-write-1.x.x.apk` 或类似格式。
2. 在手机允许「安装未知来源应用」后完成安装。
3. 首次启动后可在「工具 → 云同步」中配置 WebDAV 或 S3 服务器地址进行数据同步。
